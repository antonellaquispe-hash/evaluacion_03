Importante: las etiquetas REF representan referencias lógicas; no son claves foráneas MySQL porque cada servicio tiene una base de datos separada. Al crear una inscripción, registration-service consulta Evento y Asistente por REST. El servicio también verifica que el evento esté activo y que no se haya alcanzado su capacidad.
